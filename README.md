# Crypto Pay Nexus

Crypto payment gateway dashboard for merchants.

## Features

- Wallets, transactions and customers
- Integrations and analytics
- Compliance, docs and legal pages

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/crypto-pay-nexus.git
cd crypto-pay-nexus
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
